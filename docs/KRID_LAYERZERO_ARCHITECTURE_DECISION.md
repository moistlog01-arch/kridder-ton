# KRID LayerZero Architecture Decision

## Decision

KRID will evaluate LayerZero as the preferred omnichain infrastructure provider.

Reason:

LayerZero aligns with the long-term goal of expanding KRID across multiple ecosystems:

- TON
- Base
- Solana
- Arbitrum
- BNB Chain


## Current KRID Asset

Origin:

TON Mainnet


Standard:

TEP-74 Jetton


Properties:

- Fixed supply
- 1,000,000,000 total supply
- Mint disabled
- Admin removed
- 9 decimals


## Objective

Maintain one KRID ecosystem across chains.

Target:

TON KRID
|
LayerZero interoperability
|
Multichain KRID


## Required Confirmation

Before implementation:

1. Confirm TON Jetton compatibility

2. Confirm recommended LayerZero architecture

3. Confirm whether OFT or adapter architecture is required

4. Confirm Base deployment requirements

5. Confirm Solana deployment requirements

6. Confirm costs and timeline


## Existing Infrastructure

Already prepared:

- Base deployment wallet
- Bridge operations wallet
- Treasury wallet
- Liquidity wallet
- Technical documentation


## Current Status

Wormhole path paused pending TON compatibility.

LayerZero path under evaluation.


## Rule

No new chain deployment until official interoperability path is confirmed.
